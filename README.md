# 🗂️ Auto-Worship-Folder

## 一鍵建立崇拜投影片資料夾

自動整理經文、啟應、詩歌及固定投影片。
完成後，**雙擊 `.ppsx` 檔即可放映**。✅

▶️ **[觀看示範影片](https://youtu.be/Ux96B1j_Jw0?si=UvyG0YIuD0w-Rvht)**

## 🔐 安全

> [!TIP]
> `.vbs` 是 Windows 自動化程式，雙擊會立即執行。

#### 如何檢視程式碼

1. 右鍵按 `.vbs`
2. 選「開啟檔案方式」
3. 選「記事本」

> 不要把密碼、個人資料或內部檔案貼到公開 AI。

## ✅ 使用前

- 只支援 **Windows**
- 需要 **PowerPoint 桌面版**
- 開始前請儲存並關閉 PowerPoint

> [!IMPORTANT]
> Mac、手機及 PowerPoint 網頁版不能使用。

## 📥 第一次設定

1. GitHub 按 **Code → Download ZIP**
2. 解壓縮後，整個資料夾放到電腦，例如 `D:\崇拜`
3. **不要改名、搬動或刪除檔案**
4. 開啟 `song-folders.txt`，每行填一個詩歌投影片資料夾位置

```text
例如：
D:\崇拜資料\詩歌
C:\Users\你的名\Documents\詩歌
```

## 🚀 每星期 4 步

### 1️⃣ 填內容

填寫這三個檔案：

```text
內容-宣召及啟應.txt
內容-經訓.txt
內容-讀經.txt
```

### 2️⃣ 雙擊執行

```text
create-worship-folder.vbs
```

### 3️⃣ 輸入資料夾名稱

```text
例如：
20260906崇拜
```

> [!TIP]
> 若同名資料夾已經存在，此專案會提醒你，不會直接將其覆蓋。

### 4️⃣ 輸入詩歌名稱

用英文逗號 `,` 分隔：

```text
奇異恩典,你真偉大,靠近主
```

等待完成提示即可。PowerPoint 自動開關是正常的。

## 📁 完成後

| 檔案              | 用途             |
| ----------------- | ---------------- |
| `.pptx`           | 各項崇拜投影片   |
| `master.pptx`     | 投影片目錄       |
| `<日期>崇拜.ppsx` | **當日雙擊放映** |

找不到詩歌時，程式會留下「找不到」提示檔，請自行補回該詩歌。

## ⚠️ 注意

- 修改投影片後：在該崇拜資料夾雙擊 `refresh-master.vbs`
- 更新前先全部關閉 `.pptx` 和 `.ppsx`
- 出錯時，程式會刪除剛建立的資料夾；修正後重做
- 如 `.txt` 出現中文亂碼時，請用 **UTF-8** 儲存
