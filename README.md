# Auto-Worship-Folder（自動建立崇拜投影片資料夾）

一鍵開好一個崇拜資料夾：自動生成「宣召及啟應／經訓／讀經」投影片、複製你指定的詩歌 pptx、複製固定環節投影片，最後更新 `master.pptx` 目錄頁，並輸出可即場放映的 `.ppsx`。

---

## 一、先決條件

- Windows 電腦（本工具是 VBScript，Mac 用不到）
- 已安裝 Microsoft PowerPoint 桌面版（網頁版不行）
- 執行前先儲存並關閉所有 PowerPoint 視窗

## 二、安裝（只做一次）

1. 在 GitHub 按 **Code → Download ZIP**，解壓縮。
2. 整個資料夾放到本機或部門磁碟（例：`D:\崇拜`）。結構必須保持：

   ```
   create-worship-folder.vbs
   song-folders.txt
   內容-宣召及啟應.txt
   內容-經訓.txt
   內容-讀經.txt
   templates\dynamic\    （3 個 -template.pptx）
   templates\standard\   （固定環節 pptx、master.pptx、refresh-master.vbs）
   ```

   缺任何一項，程式開頭就會報錯並停止。

3. 開啟 `song-folders.txt`，**每行一個**存放詩歌 pptx 的資料夾路徑，由上至下逐個搜尋。存檔編碼用 **UTF-8**。

   ```
   D:\崇拜事工\崇拜用資料
   ```

## 三、每星期的操作（4 步）

### 第 1 步：填內容（3 個 txt，全部 UTF-8 存檔）

#### `內容-讀經.txt`、`內容-經訓.txt`

第一行是標題，之後每行一節；**節數與經文之間必須用 Tab 鍵分隔**，空白行會被忽略。

```
讀經：馬可福音十一12-25

12	第二天，他們從伯大尼出來，耶穌餓了。
13	遠遠的看見一棵無花果樹，樹上有葉子……
```

程式會自動按每頁字數／行數分頁，你不用自己分。

#### `內容-宣召及啟應.txt`

用 `[宣召]` 和 `[啟應]` 分段。**兩段不必齊備，有一段就可以**：

| 情況 | 結果 |
|---|---|
| 兩段都有 | 宣召 1 頁 ＋ 每對啟應各 1 頁 |
| 只有 `[宣召]` | 只出宣召頁 |
| 只有 `[啟應]` | 只出啟應頁 |
| 兩段都空 | 報錯停止 |

```
[宣召]
「我的心哪，你要稱頌耶和華，凡在我裏面的，也要稱頌祂的聖名！」

(詩篇一〇三1)

[啟應]
啟：我的心哪，你要稱頌耶和華，不可忘記祂的一切恩惠！
應：耶和華有憐憫，有恩典，不輕易發怒，且有豐盛的慈愛。

啟：祂不長久責備，也不永遠懷怒。
應：耶和華有憐憫，有恩典，不輕易發怒，且有豐盛的慈愛。

(詩篇一〇三2-3,8-12)
```

規則：

- `啟：` 一定要緊接一句 `應：`，一對一對排；漏配會報錯。全形 `：` 或半形 `:` 都接受。
- `啟：`／`應：` 後面不可留空。
- `[啟應]` 內不以 `啟：`／`應：` 開頭的行（例如尾段的經文出處），會自動接在**上一句**後面，不會另開一頁。
- 同一個段落標題不可出現兩次。
- 空白行會變成投影片上的一行空行。

### 第 2 步：雙擊 `create-worship-folder.vbs`

若偵測到有未儲存的 PowerPoint，會先提你儲存並關閉。

### 第 3 步：輸入資料夾名稱

例如 `20260906崇拜`。不可含 `\ / : * ? " < > |`。若同名資料夾已存在，程式會停止，**不會覆蓋**。

### 第 4 步：輸入詩歌名稱，用**半形逗號**分隔

```
奇異恩典,你真偉大,靠近主
```

按確定後等它跑完（PowerPoint 會在背景自動開關，屬正常）。完成會彈出提示視窗。

## 四、你會得到什麼

新資料夾（建立在程式所在位置）內：

| 檔案 | 來源 |
|---|---|
| `00_崇拜驗證碼.pptx`、`01_安靜.pptx`、`03_禱告.pptx`、`55_使徒信經.pptx`… | 由 `templates\standard` 原樣複製 |
| `02_宣召及啟應.pptx` | 由 `內容-宣召及啟應.txt` 生成 |
| `30_經訓.pptx` | 由 `內容-經訓.txt` 生成 |
| `40_讀經.pptx` | 由 `內容-讀經.txt` 生成 |
| `20_<詩歌名>.pptx` | 從 `song-folders.txt` 的路徑搜到後複製 |
| `master.pptx` | 目錄頁，已自動加上全部 pptx 的超連結 |
| `<資料夾名>.ppsx` | 由 master 另存的放映檔，**當日直接雙擊它放映** |

**搜不到的詩歌**：不會中斷，會留下一個 `(找不到) 詩歌名.txt`（內含該詩歌名）提你手動補，完成時亦會彈窗列出清單。

`50_講道.txt` 一類佔位 txt，若同名 pptx 已生成便會自動刪走；未生成的會留下，提你手動補。

## 五、常見情況

- **搜歌規則**：先搜該路徑本身的 pptx，找不到才逐層搜子資料夾。檔名**包含**你輸入的字即算命中（不分大小寫），**第一個命中即停**。所以名稱越精準越好，太短易搜錯歌。
- **手動加減投影片後想更新目錄頁**：在該崇拜資料夾內雙擊 `refresh-master.vbs`，它會重建連結並重新輸出 `.ppsx`。（不要在 `templates\standard` 內執行，程式會擋。）
- **目錄頁最多 30 個 pptx 連結**，超出會報錯。
- **`master.pptx` 或 `.ppsx` 正在開啟**會停止執行，先關閉再試。
- **中途出錯**：程式會刪走剛建立的資料夾，等於沒動過；改正後重跑即可。
- **內容 txt 空白**（或只有 BOM）會直接報錯，先填內容。
- 執行完會自動關掉它自己開的隱形 PowerPoint、清走殘留的 `~$` 鎖定檔。**你自己開著的 PowerPoint 視窗不會被動。**

## 六、進階（只在要改範本時才看）

- `templates\dynamic\宣召及啟應-template.pptx` 必須**剛好 2 頁**：第 1 頁含名為 `CALL_SCRIPTURE_1` 的文字框（放宣召），第 2 頁含名為 `CALL_RESPONSE_1` 的文字框（放一對啟／應，之後每對複製一頁）。名稱在 PowerPoint「選取範圍窗格」設定，改名會生成失敗。
- `經訓-template.pptx`、`讀經-template.pptx` 分別提供標題與內文版面，內容由程式填入並自動分頁。
- `master.pptx` 只可有 **1 張投影片**，並須保留 `AUTO_LINK_CONTAINER`（連結範圍邊界）和 `TextBox 6`（第一個連結兼字型樣板，其餘連結由它複製而成）。兩者不可刪改名稱。
- 檔名前面的數字（`00_`、`20_`、`98_`…）決定目錄頁排序，改數字即改次序。

## 七、VBS 與安全

VBS（VBScript）是 Windows 內建的自動化腳本檔。本工具用到兩個：

```text
create-worship-folder.vbs
refresh-master.vbs
```

### 查看或修改

> [!IMPORTANT]
檢閱 `.vbs` 時**不要直接雙擊**，Windows 會立即執行它。

1. 在 `.vbs` 檔案按右鍵。
2. 選 **開啟檔案方式**。
3. 選「記事本」、Notepad++ 或其他文字編輯器。
4. 修改前先備份原始檔。
5. 修改後先在測試資料夾試跑，確認正常才正式使用。

### 用 AI 檢查安全性

如你不確定 script 是否安全：

1. 用記事本開啟 `create-worship-folder.vbs` 或 `refresh-master.vbs`。
2. 複製全部程式碼。
3. 貼到你信任的 AI，並輸入：

```text
請用繁體中文解釋這段 VBS 的功能。

請檢查它有沒有刪除、覆蓋、移動或複製檔案，
執行 CMD／PowerShell、下載資料、連接網絡、
讀取密碼或上傳資料。

請列出它會讀取、建立、修改或刪除的檔案和資料夾。
請不要修改程式碼，只報告實際功能和風險。
```
> [!CAUTION]
> 不要把密碼、API Key、個人資料、教會內部資料或完整電腦路徑貼到公開 AI 對話。
